# Lesson 1/48 · Phase 1: What AI, ML, Deep Learning and Generative AI Are

> **Why this matters:** These four terms come up everywhere. Once you know how they fit together, all the AI news and tools make far more sense.

## The core idea

Think of them as **circles inside circles**, like a set of nesting dolls:

1. **Artificial Intelligence (AI)** is the biggest circle. It means any computer system that does something we'd normally call "smart": understanding speech, recognising faces, playing chess, giving directions.
2. **Machine Learning (ML)** sits inside AI. Instead of people writing every rule, the computer **learns the rules from examples**. For example, it studies thousands of emails until it can tell spam from real mail.
3. **Deep Learning (DL)** sits inside ML. It's a powerful kind of ML that uses **neural networks**: many layers of simple maths units, loosely inspired by brain cells. It's great with messy data like photos, audio and text.
4. **Generative AI** sits inside deep learning. These models **create new things** (text, images, music, code) instead of only sorting or predicting. ChatGPT, Claude and image generators are all generative AI.

### Everyday analogy: food 🍽️

- **AI** is "food": the whole category.
- **ML** is "cooked food": made by following a process.
- **Deep learning** is "baked goods": one powerful cooking method.
- **Generative AI** is "cakes you design yourself": baking used to create something new.

Every cake is food, but not all food is cake. In the same way, all generative AI is AI, but not all AI is generative.

## Worked example: sorting everyday tools

| Tool | Which circle? | Why |
|---|---|---|
| A 1990s chess computer with hand-written rules | AI (not ML) | Smart, but people wrote the rules |
| Gmail spam filter | ML | Learned from examples of spam |
| Phone face unlock | Deep learning | Neural network reads images |
| ChatGPT / Claude writing an email | Generative AI | Creates new text |

## Try it yourself (15 min)

Write down 5 apps you used this week (maps, YouTube, a banking app, a translator, a chatbot, for example). For each one:

1. Where do you think AI is being used inside it?
2. Which circle does it belong to: AI, ML, deep learning or generative AI?
3. Does it **predict/sort** something, or **create** something new?

There are no wrong answers. The goal is to start spotting AI around you.
